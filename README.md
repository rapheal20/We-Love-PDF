## We love PDF
We love PDF is a complete recreation of the website I LOVE PDF. It is being coded by Anael and Rapheal. 

To make this challenging, we will not use any libraries except default python ones. We will do direct implementation of libraries such as PyPDF2 by editing the PDF source code.

The features implemented will be: 
1. Merge PDF (Done by Rapheal)
2. Split PDF (Done by Anael)
3. Compress PDF (Done by Rapheal)
4. PDF to Word (work in progress by Anael)
5. PDF to PowerPoint 
6. PDF to Excel
7. Word to PDF 
8. PowerPoint to PDF
9. Excel to PDF
10. Edit PDF 
11. PDF to JPG (work in progres by Rapheal)
12. JPG to PDF 
13. Sign PDF 
14. Watermark 
15. Rotate PDF 
16. HTML to PDF 
17. Unlock PDF 
18. Protect PDF 
19. Organize PDF 
20. PDF to PDF/A
21. Repair PDF 
22. Page numbers
22. Scan to PDF 
23. OCR PDF 
24. Compare PDF 
25. Redact PDF 
26. Crop PDF 
27. PDF Forms 
28. AI summarizer 
29. Translate PDF
30. PDF to Markdown

We will use flask python for backend and html css for frontend.
